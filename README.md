# Pixels to Biomarkers — workshop website

Source of **https://pixels2biomarkers.github.io/p2b2026/**, the website of the IEEE BigData 2026 workshop
*1st Workshop on Big Data for Computational Pathology and Multi-Omics: From Pixels to Biomarkers*.

The site is a single page built with [Jekyll](https://jekyllrb.com/) on the
[Cayman](https://github.com/pages-themes/cayman) theme and published by GitHub Pages.
There is no build step to run yourself: every push to `main` is rebuilt and deployed
automatically (usually within a minute or two).

## Editing the site

| What you want to change | File to edit |
| --- | --- |
| Deadlines / important dates | `_data/dates.yml` |
| Topics of interest | `_data/topics.yml` |
| Keynote speakers | `_data/speakers.yml` — set `confirmed: true` to publish a speaker; while nobody is confirmed the section shows "To be announced" |
| Program co-chairs (cards with bios) | `_data/chairs.yml` |
| Program committee | `_data/committee.yml` |
| Contact email, submission link, venue, conference link | `_config.yml` |
| Prose: About, Call for Papers, Submission Guidelines, Contact | `index.html` |
| Navigation, header/hero, footer | `_layouts/default.html` |
| Header animation (sliding window / drift / static) | `hero_animation` in `_config.yml` |
| Colours and styling | `assets/css/style.scss` (the palette is defined at the top) |
| Favicon, hero tissue image, social-sharing image | `assets/img/` — the H&E-style hero tile is generated by `tools/make_hero_texture.py` (try `--seed N` for a different arrangement) |

Adding a headshot: put the image in `assets/img/people/` (square, ≥ 300×300 px) and set
`photo: /assets/img/people/name.jpg` on the person's entry. Personal homepages go in `url:`.

Quick edits can be made directly on GitHub: open the file, click the pencil icon,
edit, and *Commit changes*. The live site updates automatically.

## Previewing locally (optional)

Requires Ruby ≥ 3.0.

```bash
bundle install
bundle exec jekyll serve --livereload
# then open http://127.0.0.1:4000/p2b2026/
```

## Layout of the repository

```
_config.yml          site settings (title, event details, links, plugins, url/baseurl)
index.html           the page content
_layouts/default.html  page skeleton: navigation, hero header, footer
_includes/           small partials: dates, speakers, chairs, committee, avatar
_data/               all lists shown on the page (YAML)
assets/css/style.scss  styles (overrides the Cayman theme's variables, then adds components)
assets/img/          favicon, hero tissue tile (hero-he.jpg), social-sharing image
tools/               generator script for the hero tissue tile (not published)
```
